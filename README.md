Bank Customer Churn Analysis

Project Overview

This project analyzes customer churn behavior in the banking sector to identify the factors influencing customer attrition. The goal is to help businesses improve customer retention strategies by generating actionable insights through data analysis and visualization.

---

Business Problem

Customer churn directly impacts revenue and customer lifetime value in the banking industry. Understanding why customers leave helps organizations improve retention, customer satisfaction, and long-term profitability.

---

Project Objective

- Analyze customer churn patterns
- Identify factors influencing customer attrition
- Perform exploratory data analysis (EDA)
- Generate business insights for decision-making
- Build an interactive dashboard for performance monitoring

---

Tools & Technologies Used

- Kaggle (Data Cleaning & Processing)
- MySQL (Exploratory Data Analysis - EDA)
- Power BI (Dashboard & Data Visualization)
- Python (Pandas, NumPy, Matplotlib)

---

Dataset Information

The dataset contains banking customer information such as:

- Customer ID
- Age
- Gender
- Geography
- Credit Score
- Balance
- Tenure
- Number of Products
- Active Member Status
- Estimated Salary
- Churn Status

---

Project Workflow

1. Data Cleaning (Kaggle)

- Imported dataset
- Checked missing values
- Removed duplicate records
- Fixed inconsistent values
- Performed data formatting and preprocessing

2. Exploratory Data Analysis (MySQL)

Performed EDA using SQL queries to analyze:

- Customer churn distribution
- Geography-wise churn analysis
- Age-group analysis
- Balance distribution
- Active vs inactive customers
- Product usage patterns
- Credit score and churn relationship

3. Dashboard Development (Power BI)

Built an interactive dashboard to monitor:

- Total Customers
- Churn Customers
- Churn Rate %
- Retention Rate %
- Geography-wise churn
- Age Group Analysis
- Product-wise churn
- Balance Band Analysis
- Active vs Inactive Customers

---

Key Business Insights

- Customers with shorter tenure showed a higher probability of churn.
- Inactive customers were more likely to leave the bank.
- Customers using multiple banking products demonstrated higher retention.
- High-balance customer churn represented a potential business risk.
- Customer churn varied across geographic regions.
